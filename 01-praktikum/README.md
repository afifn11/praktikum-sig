# Praktikum 1: Aplikasi Google Map 1

## Deskripsi
Modul pertama ini difokuskan pada pengenalan dasar lingkungan aplikasi Google Maps. Praktikum ini mencakup teknik pembedahan titik koordinat (*latitude* & *longitude*), manipulasi parameter *zoom* URL, serta proses perekaman (*geotagging*) data keruangan untuk objek *Point of Interest* (POI).

## Tujuan Praktikum
- Memahami konsep dasar visualisasi peta vektor pada Google Maps.
- Memahami manajemen peta dasar dan teknik *tagging* titik lokasi spesifik.
- Menyusun sekumpulan data koordinat ke dalam *file* berformat `.csv` dan mengimpornya guna membangun peta tematik mandiri pada layanan Google My Maps.

## Isi Direktori
Folder ini berisi berkas data tabular `.csv` hasil ekstraksi koordinat secara mandiri, di antaranya:
- Data lokasi fasilitas publik tematik (Taman Kota, Setu/Waduk, Rumah Sakit, GOR).
- Data klasterisasi penginapan/hotel hasil pencarian spesifik.
- Data lokasi favorit di wilayah Kota Depok.
