# Praktikum 3: Aplikasi Google Map 3

## Deskripsi
Modul ketiga difokuskan pada pemetaan dimensi luasan melalui mekanisme digitasi spasial **Area Polygon**. Modul ini tidak sekadar merekam satu titik (*point*), melainkan melibatkan proses penarikan garis (*on-screen digitizing*) atas sekumpulan simpul (*vertices*) yang saling bersambung membentuk suatu batasan fisik (*boundary*) objek secara akurat di atas citra satelit.

## Tujuan Praktikum
- Memahami konsep representasi spasial dengan menggunakan geometri bentuk tertutup (area poligon).
- Menguasai prosedur operasional *tool* "Add line or shape" pada lingkungan Google My Maps.
- Melakukan digitasi luasan secara rinci untuk kategori fasilitas Ruang Terbuka Hijau (RTH) dan tata batas Administrasi Wilayah.
- Memahami signifikansi format data spasial **KML** (*Keyhole Markup Language*) untuk menyimpan dan mendistribusikan metadata struktur batas poligon secara presisi.

## Isi Direktori
Folder ini mendokumentasikan pasangan hasil ekspor *file* spasial `.kml` (menyimpan geometri vektor) dan `.csv` (menyimpan rekaman tabular), yang terdiri atas objek:
- **Taman Kota Jakarta:** Taman Monas, Gelora Bung Karno, Kebun Binatang Ragunan, Taman Mini Indonesia Indah, dan Tebet Echo Park.
- **Batas Wilayah Administratif Makro:** Provinsi DKI Jakarta, Provinsi DI Yogyakarta, dan Kota Administrasi Depok.
